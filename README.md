# KampungKu

KampungKu adalah permainan ladang kampung yang cozy dan santai, diinspirasikan oleh suasana life sim yang tenang. Anda boleh:

- menanam pelbagai jenis benih
- menyiram tanaman
- menuai hasil dan menjana pendapatan
- menjaga tenaga harian
- berinteraksi dengan warga kampung
- teruskan hari demi hari untuk membangunkan ladang anda

## Cara main

1. Pilih alat: Tangan, Siram atau Tanam.
2. Pilih benih yang anda mahu tanam.
3. Klik petak ladang untuk menjalankan tindakan.
4. Siram tanaman agar cepat membesar.
5. Tuai ketika sudah siap untuk dapat duit.
6. Beli benih baru dari panel Beli Benih.
7. Tekan Hari Seterusnya untuk bergerak ke hari berikutnya.

## Run lokal

Buka `index.html` dalam browser untuk bermain.

Untuk hosting statik seperti Netlify atau GitHub Pages, cukup upload folder ini sebagai laman web statik.
